### 👨‍💻 About me

I have been designing and building WordPress websites professionally since **2016**, from fully custom themes for established businesses to bespoke plugins for WooCommerce stores. Alongside WordPress I build bots and commerce tools for **Bale messenger**, and I have shipped a **Flutter Android app** that manages a WooCommerce store end to end.

My focus is genuinely tailored solutions rather than off-the-shelf templates: every project starts with a close reading of the business need and ends with a hand-off the client can confidently run themselves.

- 🎨 **4** custom themes live in daily production
- 🧩 **1** published plugin on WordPress.org
- 🤖 **3** independent Bale products
